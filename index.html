Prerequisites

PyFIA requires Python 3.9+ and the following packages. We recommend using a conda environment.

Option A — conda (recommended)
conda create -n pyfia python=3.11 conda activate pyfia conda install -c conda-forge geopandas pandas numpy scipy matplotlib conda install -c conda-forge rasterio contextily pyproj scikit-learn
Option B — pip
pip install geopandas pandas numpy scipy matplotlib rasterio contextily pyproj mapclassify

Download FIA Data

Download CSV data files for your state from the FIA DataMart. You need at minimum: TREE, COND, PLOT, COUNTY, TREE_GRM_ESTN, POP_STRATUM, POP_PLOT_STRATUM_ASSGN tables.

# Files needed (example for Maine): ME_TREE.csv ME_COND.csv ME_PLOT.csv ME_COUNTY.csv ME_TREE_GRM_ESTN.csv ME_POP_STRATUM.csv ME_POP_PLOT_STRATUM_ASSGN.csv

Download US Boundary Shapefile

Download county/state boundaries from the US Census TIGER/Line files or use the provided us_boundary.shp included with PyFIA.

Running Your Script

cd /path/to/your/project python generated_script.py

Results are saved as CSV files in _Results/ and maps as PNG files.

Required Project Folder Structure

PyFIA expects a specific directory layout. Place all PyFIA Python files and your data in the same root folder as shown below.

MyProject/ ├── PyFIA.py # ← your generated script goes here ├── _pyFIA_Plot_Stats.py ├── _pyFIA_Regional_Stats.py ├── _pyFIA_Visualization.py ├── _pyFIA_Interpolation.py ├── _pyFIA_Climate.py ├── _pyFIA_Bookkeeping.py ├── _pyFIA_Tools.py │ ├── ME_CSV/ # State CSV data folder │ ├── ME_TREE.csv │ ├── ME_COND.csv │ ├── ME_PLOT.csv │ ├── ME_COUNTY.csv │ ├── ME_TREE_GRM_ESTN.csv │ ├── ME_POP_STRATUM.csv │ └── ME_POP_PLOT_STRATUM_ASSGN.csv │ ├── _US_Boundary/ │ └── us_boundary.shp # + .dbf, .shx, .prj files │ ├── _Results/ # Output folder (auto-created) │ ├── _NLCD/ # For interpolation only │ └── NLCD_2024.tif │ ├── _ClimateNA/ # For climate analysis only │ └── *.tif # ClimateNA raster files │ └── _AOI/ # For AOI summaries only └── *.shp

Notes

• The _Results/ folder is created automatically.
• For multi-state analyses, create a separate CSV folder per state (e.g., GA_CSV/).
• NLCD and ClimateNA data are only needed for interpolation and climate modules respectively.
